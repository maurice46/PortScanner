Socket: An endpoint that allows two devices or programs to communicate with each other over a network.

TCP: Establishes a connection before exchanging data, ensuring data arrives reliably, in order, and retransmits missing data. 

UDP: Sends data without establishing a connection first, prioritizing speed and low overhead over guaranteed delivery. 

What happens when a computer attempts to connect to a port?
    1. Your computer sends a SYN packet (TCP packet with a SYN flag enabled)
    2. The destination computer responds:
        a. Open Port: The server responds with SYN-ACK (SYN -> SYN-ACK)
        b. Closed Port: The server responds with RST (Reset: SYN -> RST-ACK)
        c. Filtered Port: Your reqest receives no response, or an error message (SYN -> No response / ICMP error)
    3. TCP establishes the connection 
        - If the port is open, TCP completes the 'three-way handshake'
        - SYN (Request)
        - SYN-ACK (Acknowledgement)
        - ACK (Confirmation)
        - After this, the two computers can exchange data 

socket.connect_ex()
- it attempts to establish a connection to a specified IP address and port
- connect() raises an exception if the connection fails
- connection_ex() returns an error code instead of raising an exception for connection errors 

What is the difference between an open port, closed port and filtered port?
- A port is a communication endpoint associated with a particular network service
- Port 21 = FTP, Port 22 = SSH, 25 = SMTP, 53 = DNS, exception
- Can have different states depending on whether a service is listening and how the network responds 
- Open Port means a service is listening and accepting connections
- Closed Port means the destination computer is reachable, but no service is accepting connections 
- Filtered Port means a firewall or network device is preventing you from determining whether the port is open or closed
